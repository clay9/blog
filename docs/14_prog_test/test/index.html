    测试总览

    1. 单元测试
      单元测试, 没必要测试每一个函数,
      只需要测试class 或单元(namespace) 对外的public 接口即可

    2. 业务测试

    单元测试还是站在程序的角度去看的, 看的是模块对外提供的接口
    而业务测试, 则是完全站在用户或业务角度去看的
