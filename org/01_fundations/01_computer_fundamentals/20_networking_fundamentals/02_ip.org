#+title: IP 协议

* IP 地址
  IP 地址分为32位, 128位. 以IPV4 (32 位) 来举例.

  192.168.1.1/25

  1. 192.168.1.1: 把32 bit 的二进制用十进制的a.b.c.d 表示
  2. /25: 表示前25 bit为网络位数; 32-25 剩下的表示主机位数


  几个特殊的IP 地址:
  网络地址: 网络位保持原址, 主机位全0. 是对外展示的本子网的IP 地址
  广播地址: 网络位保持原址, 主机位全1


  所以刚刚的192.168.1.1/25 表示:
  - 网络地址: 192.168.1.0
  - 广播地址: 192.168.1.127
  - 可用主机: 192.168.1.1 ~ 192.168.1.126. 共有2^7 - 2 = 126 个
